.. _api-utility:

API: internals
*********************************************

``cinnamon.utility`` is where the registry's own machinery lives: the dependency
graph, the key parser, the static analyzer behind ``cmn-check``, the exception
types, and the suggestion engine that turns a typo into a "did you mean". A
project does not import these, but reading them is the fastest way to see how a
build actually proceeds.
